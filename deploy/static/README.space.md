# Watch Lab — public feature demo

This zero-cost static Space runs the open-source
[Watch Lab](https://github.com/AntreasAntoniou/watch-lab) interface against 24 fictional
records. It demonstrates arbitrary typed filters, multi-column sorting, search, and
pagination without publishing IMDb data.

To explore IMDb's non-commercial datasets, install Watch Lab locally and download the data
directly from IMDb under its terms. This public Space never downloads or serves that dataset.
